# TypeStatus 用户指南

## 它能做什么

TypeStatus 会常驻在 Windows 系统托盘中，用鼠标光标颜色提示当前输入状态：

| 光标颜色 | 表示状态 |
| --- | --- |
| 红色 | 下一次通常会输入中文 |
| 蓝色 | 下一次通常会输入英文 |
| Windows 原本的颜色 | 当前状态无法可靠判断，或 TypeStatus 已暂停 |

程序会改变文本区域里的 I-beam 工字光标，也会给普通箭头原本的深色描边着色。光标大小、形状和热点位置保持不变。

## 使用前须知

当前版本是早期 MVP，适合试用和反馈，不建议把它视为已经覆盖所有软件与输入法的正式稳定版。

已经验证：

- Windows 自带英文键盘
- 微信输入法的中文模式
- 微信输入法的英文模式
- 搜狗输入法的中文模式
- 搜狗输入法的英文模式
- 百度输入法的中文模式
- 百度输入法的英文模式

尚未完成正式验证：

- 微软拼音
- 其他第三方输入法

TypeStatus 使用 Windows 通用输入法接口，理论上可以识别一部分兼容这些接口的输入法，但“使用通用接口”不等于所有输入法都会返回一致结果。

## 启动与退出

1. 双击 `TypeStatus.exe`。
2. 程序不会显示主窗口，请在任务栏右侧的系统托盘中寻找 TypeStatus 图标；图标有时会被收进“隐藏的图标”。
3. 将输入法切换到中文或英文，观察鼠标光标颜色。
4. 右键托盘图标可以查看状态、暂停着色或退出。

正常退出时，TypeStatus 会立即恢复你当前 Windows 光标方案。

## 托盘菜单

- **当前状态**：显示最近一次识别到的中文、英文或未知状态。
- **暂停并恢复系统光标**：暂时停止检测和着色，并恢复 Windows 原有光标。
- **继续状态着色**：从暂停状态恢复工作。
- **退出**：恢复系统光标并关闭程序。

双击托盘图标可以查看简短的颜色说明。

## 隐私与安全

TypeStatus：

- 不读取或保存你输入的文字；
- 不监听或记录按键；
- 不连接网络；
- 不注入其他应用进程；
- 不需要管理员权限；
- 只读取当前焦点线程的键盘布局和 IME 提供的开关状态。

由于程序需要替换当前用户会话中的标准系统光标，光标颜色变化并不限于某一个应用。这是 Windows `SetSystemCursor` 接口本身的工作方式。

## 常见问题

### 为什么有些软件里的光标没有变色？

部分软件会绘制自己的鼠标光标，而不是使用 Windows 标准箭头或 I-beam。TypeStatus 不注入其他进程，因此无法强制修改这些自绘光标。

### 为什么进入管理员程序后颜色恢复成系统默认？

普通权限程序可能无法向更高权限的窗口查询 IME 状态。TypeStatus 不会为了绕过这个限制而注入进程或默认请求管理员权限；无法可靠判断时会保守地恢复系统默认光标。

### 为什么光标状态偶尔有一点延迟？

程序默认每 200 毫秒检查一次状态，以平衡响应速度和资源消耗。因此状态变化到光标变化之间最多可能有约 0.2 秒延迟，IME 自身响应慢时可能更长。

### 程序异常关闭后光标没有恢复怎么办？

依次尝试：

1. 重新启动 TypeStatus，然后从托盘菜单选择“退出”。
2. 打开 Windows“鼠标属性”中的“指针”页面，重新应用当前指针方案。
3. 注销并重新登录 Windows。

### TypeStatus 会修改我的鼠标方案文件吗？

不会。它只在当前登录会话中替换标准箭头和 I-beam 的系统映射，不会改写原始 `.cur` 文件。正常退出时会要求 Windows 重新加载当前指针方案。
